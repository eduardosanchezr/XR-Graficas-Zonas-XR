Function:

How to write a function:
Declare parameters with f(u,v)
Declare a vector with square brackets [x,y,z]
Leave out any parameter (e.g. [2,3,1] or [a,b,1]) to draw a single point/vector from the origin instead of a curve or surface
Any point/vector automatically gets live X/Y/Z sliders (menu on the right in VR) so you can drag its value in real time

Modo:

Matriz: visualiza como una matriz 3x3 transforma el espacio - la esfera unitaria se vuelve un elipsoide, U' = A x U, y se resalta el eigenvector dominante.
Vectores: suma o producto cruz de dos vectores A y B, con sliders y la regla del triangulo / el paralelogramo.
Campo vectorial: dibuja una cuadricula de flechas para F(x,y,z) = [...]. Escribe la formula abajo.

Campo vectorial - formula:

Debe declarar los 3 parametros, ej: F(x, y, z) = [fx, fy, fz]
Rotacional: F(x,y,z) = [-y, x, 0]
Radial: F(x,y,z) = [x, y, z]
Espiral: F(x,y,z) = [y, -x, z*0.3]

Examples:

f(t)=[cos(t), sin(t), t] f(u,v)=[u, v, u*v*0.1] f(u,v)=[cos(u),sin(v),2 * cos(v)] Trefoil Knot Möbius strip Helicoid Torus Vector (with live sliders): [2, 3, 1] sin(u)*cos(v) (try Riemann sums on this one)
